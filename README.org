* Introduction

indielinks brings [[https://web.archive.org/web/20080906021806/http://delicious.com/][del.icio.us]]-style social bookmarking to the [[https://en.wikipedia.org/wiki/Fediverse][Fediverse]].

[[https://en.wikipedia.org/wiki/Delicious_(website)][del.icio.us]] was a web service in the aughts & early teens to which you could not only upload your bookmarks, but share them, discuss them and discover content shared by others (AKA "social bookmarking"). The [[https://en.wikipedia.org/wiki/Fediverse][Fediverse]] is a collection of decentralized social networking services that federate with one another over the [[https://www.w3.org/TR/activitypub/][ActivityPub]] protocol; the one you've mostly likely heard of is [[https://joinmastodon.org/][Mastodon]].

* Pre-requisites
:PROPERTIES:
:CUSTOM_ID: pre_requisites
:END:

To run indielinks locally, you'll need to have [[https://www.scylladb.com/][ScyllaDB]] installed, or Docker (to pull & run ScyllaDB images). See the [[INSTALL.org]] file for details.

To build from source, the Rust stable [[https://rustup.rs/][toolchain]] is required. The integration tests require [[https://www.docker.com/][Docker]], as well as [[https://www.haproxy.org/][haproxy]]. You'll want [[https://trunkrs.dev/][trunk]] for building & working on the frontend, along with [[https://tailwindcss.com/][TailwindCSS]], and the [[https://nickel-lang.org/getting-started/][nickel]] configuration language tool (see [[file:HACKING.org][HACKING.org]] for more information on, well, on hacking on the project).
* Installation
:PROPERTIES:
:CUSTOM_ID: installation
:END:

I'm in the process of standing-up the first indielinks instance (it will be called [[https://indiemark.sh][indiemark.sh]]; it's up intermittently at the time of this writing). In the meantime, indielinks can be installed locally, running against ScyllaDB. You can [[#pre_requisites][build]] the proejct from source, but I maintain an Arch package on the [[https://aur.archlinux.org/packages/indielinks-git][AUR]], and a Debian binary package on my personal [[https://www.unwoundstack.com/distros.html#indielinks][site]]. See [[INSTALL.org]] for details.
* Status & Roadmap

I'm using indielinks today, running it as a systemd unit on bare metal to save bookmarks, maintain reading lists, & post to the Fediverse (via a CloudFlare tunnel-- I'm [[https://indiemark.net/.well-known/webfinger?resource=acct:sp1ff@indiemark.net][sp1ff@indiemark.net]], there). The screenshots above were taken from there. I'm currently focused on standing-up the first instance at [[https://indiemark.sh][indiemark.sh]] (perhaps publicly, perhaps by invitation); knocking-off known issues, adding this or that "must have" feature, & so on.

You can read more about the project & goals [[https://www.unwoundstack.com/blog/indielinks.html][here]]. I presented on the project last year at the [[https://www.meetup.com/vancouver-rust/events/307731034/][Vancouver Rust Meetup]] (recording [[https://www.youtube.com/watch?v=aztJzpBRFAQ][here]]).

In the meantime, comments, suggestions and contributions are welcome, on [[https://indieweb.social/@sp1ff][Mastodon]], in the [[https://github.com/sp1ff/indielinks/issues][issues]] or at [[mailto:sp1ff@pobox.com][sp1ff@pobox.com]]. In particular, if you're a frontend developer who'd be interested in helping out, I'd love to hear from you.
